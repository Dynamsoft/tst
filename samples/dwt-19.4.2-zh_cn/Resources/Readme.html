Dynamic Web TWAIN SDK

Resources folder reference & quick-start guide

Version 19.4.2 Updated 2026-07-28 Product: Dynamic Web TWAIN
⚡ Quick Start
  1. Copy Resources to your project directory.
  2. Open dynamsoft.webtwain.config.js and enter your license key.
  3. Include dynamsoft.webtwain.initiate.js and dynamsoft.webtwain.config.js in your HTML page.
  4. Modify the HTML page to use the SDK for document scanning.
  5. Open your page in a browser — the SDK will prompt to install the service if needed.

JavaScript Libraries

File Description Type

dynamsoft.webtwain.initiate.js Core library entry point. Do not modify. Core

src/dynamsoft.webtwain.viewer.js

addon/dynamsoft.webtwain.addon.barcodereader.js Barcode Reader — detect and decode barcodes in scanned images. Add-on
addon/dynamsoft.webtwain.addon.pdf.js PDF Rasterizer — render and convert PDF pages. Add-on
addon/dynamsoft.webtwain.addon.webcam.js Webcam Capture — acquire images from webcams. Add-on
addon/dynamsoft.upload.js Upload Module — handles HTTP file uploads to your server. Add-on

Service Installers (dist/)

End-user installers for the Dynamic Web TWAIN Service — required on each client machine.

Platform Installer

macOS DynamicWebTWAINServiceSetup.pkg
Linux (RPM) DynamicWebTWAINServiceSetup.rpm
Linux (Debian x64) DynamicWebTWAINServiceSetup.deb
Linux (Debian ARM64) DynamicWebTWAINServiceSetup-arm64.deb

A LICENSE file is also included in dist/.

If your users lack administrative privileges for installation, or if they are running on a special CPU architecture (e.g., MIPS), visit this page to obtain a suitable installer. Contact us if it still cannot meet your environment's requirements.
